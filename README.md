# 💰 Бюджетный бюджет

Веб-дашборд для учёта общих расходов семей, соседей и групп друзей. Работает совместно с Telegram-ботом [@Kopiiiilka_bot](https://t.me/Kopiiiilka_bot) — общая база данных SQLite.

## Возможности

- 🔐 **Аккаунты** — регистрация и вход по email/паролю, приватные группы
- 👥 **Группы** — создание, вход по коду, участие в нескольких группах
- 💸 **4 способа ввода трат** — текст, голос (ASR), фото чека (VLM), файл PDF
- 🤝 **Совместные траты** — выбор участников, деление поровну
- 💰 **Баланс** — автоматический расчёт кто кому должен, упрощение долгов
- 🎯 **Бюджет** — произвольный срок, контроль лимита, история прошлых
- 📊 **Графики** — 4 типа (круговая, столбцы, строки, область) + динамика по месяцам
- 🤖 **AI-анализ** — оптимизация, напоминания, прогноз, свободные вопросы
- 💱 **Мультивалютность** — 10 валют, ежедневный курс, копейки/центы
- 🏷 **Категории** — 14 встроенных + кастомные (создание/редактирование/эмодзи)
- 🔁 **Регулярные траты** — автосоздание по расписанию
- 📅 **Запланированные траты** — резервирование бюджета, уведомления
- 🎯 **Финансовые цели** — копилки с прогрессом
- 📤 **Экспорт** — CSV и PDF
- 🌙 **Тёмная тема**

## Технологии

- **Framework:** Next.js 16 (App Router, TypeScript)
- **UI:** Tailwind CSS 4, shadcn/ui, recharts, framer-motion
- **DB:** Prisma ORM + SQLite
- **Auth:** email/пароль (scrypt + HMAC-signed JWT cookie)
- **AI:** z-ai-web-dev-sdk (GLM-4-Plus, GLM-4.6V, ASR)
- **State:** TanStack Query, next-themes

## Быстрый старт (3 команды)

```bash
# 1. Установить зависимости
bun install

# 2. Создать базу данных (создаст .env, сгенерирует Prisma client, применит схему)
bun run setup

# 3. Запустить dev-сервер
bun run dev
```

Откройте http://localhost:3000 — сайт откроется с демо-данными (группа «Квартира на Ленина» с 3 участниками и 14 расходами).

## Регистрация и вход

- **Без аккаунта** — видна демо-группа и любые публичные группы (`ownerId = null`)
- **После регистрации/входа** — видны демо-группы + свои собственные приватные группы
- Созданные залогиненным пользователем группы **приватны** — их видит только владелец
- Кнопки **«Войти»** и **«Регистрация»** в шапке; меню аккаунта с выходом

Пароли хранятся в виде scrypt-хеша (соль + хеш, hex). Сессия — httpOnly cookie с HMAC-подписанным JWT (30 дней). Секрет `AUTH_SECRET` берётся из `.env`, при отсутствии — стабильный dev-fallback.

## Привязка Telegram-аккаунта

Чтобы не дублироваться в участниках групп (один человек = один участник и на сайте, и в боте):

1. Войдите на сайте → меню «Аккаунт» → **«Привязать Telegram»**
2. Нажмите **«Сгенерировать код»** — получите одноразовый код (действителен 10 минут)
3. Откройте бота [@Kopiiiilka_bot](https://t.me/Kopiiiilka_bot) в Telegram
4. Отправьте команду `/bind КОД` (например, `/bind QSWHZD`)
5. Бот ответит «✅ Аккаунт привязан» — диалог на сайте обновится автоматически

После привязки:
- Вы — **один участник** во всех группах (и на сайте, и в боте)
- Трата, добавленная в боте, видна на сайте под вашим именем, и наоборот
- Группа, созданная в боте, видна на сайте; вход по коду — без дубликата участника
- Бот и сайт используют **одну базу данных** — изменения мгновенны

## Переменные окружения

`.env` создаётся автоматически при `bun run setup`. Минимальное содержимое:

```
DATABASE_URL=file:./db/custom.db
```

Опционально для production:

```
AUTH_SECRET=your-random-secret-at-least-32-chars
```

Сгенерировать секрет: `openssl rand -hex 32`

## Telegram-бот

Бот [@Kopiiiilka_bot](https://t.me/Kopiiiilka_bot) работает как мини-сервис в `mini-services/tg-expense-bot/` и делит ту же базу данных SQLite. Траты, добавленные в боте, мгновенно видны на дашборде, и наоборот.

### Запуск бота

```bash
cd mini-services/tg-expense-bot
bun install
# Создайте .env (пример ниже)
bun run db:generate
bun run db:push
bun run dev
```

`.env` для бота (важно: `DATABASE_URL` должна указывать на **тот же файл**, что и у сайта):

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=file:/абсолютный/путь/к/db/custom.db
BOT_PORT=3002
```

Токен бота выдаёт [@BotFather](https://t.me/BotFather) (команда `/newbot`).

### Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню |
| `/add` | Добавить трату |
| `/balance` | Кто кому должен |
| `/chart` | Графики |
| `/groups` | Список групп |
| `/ai` | AI-анализ |
| `/bind КОД` | Привязать аккаунт сайта (код с сайта) |
| `/help` | Помощь |

### Общая БД

Сайт и бот читают из одного файла `db/custom.db`. Если запускаете на разных машинах — перенесите БД или используйте общий том. На одной машине просто укажите одинаковый абсолютный путь в обоих `.env`.

## Запуск на другом устройстве

```bash
# 1. Распакуйте zip
unzip budgetnyy-byudzhet.zip -d byudzhet
cd byudzhet

# 2. Установите зависимости сайта
bun install

# 3. Создайте БД + .env (автоматически)
bun run setup

# 4. Запустите сайт
bun run dev
# → http://localhost:3000

# 5. (опционально) Запустите бота
cd mini-services/tg-expense-bot
bun install
# Создайте .env с TELEGRAM_BOT_TOKEN и DATABASE_URL на тот же db/custom.db
bun run db:generate && bun run db:push
bun run dev
# → бот подключится к Telegram, health на http://localhost:3002/health
```

**Важно:** бот использует long-polling. Если запускаете бота на одной машине, а на другой он уже работает — будет конфликт 409. Оставьте бота работать **только на одной** машине.
